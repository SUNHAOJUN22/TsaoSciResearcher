# Code of Conduct

TsaoDFT welcomes technically rigorous, respectful participation.

Participants must:

- discuss evidence, methods and code without personal attacks;
- state uncertainty and conflicts of interest honestly;
- respect licenses, confidentiality, privacy and laboratory/site rules;
- avoid publishing credentials, exploit details, proprietary structures or restricted scientific files;
- distinguish reproducible evidence from opinion, hypothesis and conceptual illustration;
- accept correction when a claim exceeds its support level.

Harassment, discrimination, threats, deliberate deception, doxxing, plagiarism, fabricated data and attempts to bypass security or approval controls are not acceptable.

Report conduct concerns to the maintainer through a minimal issue or the private security-reporting path when confidentiality is needed. The maintainer may edit, hide or remove abusive content and restrict participation. Enforcement decisions should preserve relevant evidence while minimizing unnecessary disclosure.
