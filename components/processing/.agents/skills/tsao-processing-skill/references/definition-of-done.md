# Definition of done

- Every flow carries a basis, unit, time basis, and component identity.
- Every component closes independently; total-flow equality cannot hide composition substitution.
- Any required FAIL propagates to overall FAIL; HOLD and NOT_EVALUATED never become PASS.
- Undefined metrics remain structured undefined values, never physical zero.
- Public packaging parses record classifications and fails closed.
- Software, engineering, and HSE evidence are separate.
- Missing owner classification preserves `BLOCKED_CONTROLLED_METADATA_CLASSIFICATION`.
