# Definition of done

- Raw and canonical quantities are both preserved.
- A conversion changes the value and unit together and only within one dimension.
- Formula errors and missing dependencies never become physical zero.
- Missing ranking criteria never create a cost advantage.
- Source, confidentiality, license, and provenance survive every data path.
- AI egress is minimal, previewed, consented, and policy-bound.
- Screening output never impersonates certification, regulatory compliance, or material release.
- The final status remains `SOFTWARE_VALIDATED_FOR_SCREENING` without qualified external evidence.
