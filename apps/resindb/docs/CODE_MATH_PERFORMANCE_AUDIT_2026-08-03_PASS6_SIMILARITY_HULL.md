# ResinDB Pro 数理程式与性能审计：第六轮相似度与凸包（2026-08-03）

## 1. 本轮范围

本轮限定在两条生产链：

1. `src/workers/similarityWorker.ts` → `SimilarityGraph.tsx`；
2. `src/lib/math/convexHull.ts` → `CanvasScatterGraph.tsx`。

不改变数据库内容，不改动 PCA、聚类、回归或其他科学模型。

## 2. 相似度原实现的确定性问题

### A1. 缺失维度可导致相似度虚高

原算法先对缺失值做均值填充，再将每行单位化。缺失项在标准化后成为零，但边结果没有记录两条材料实际共享了多少有效特征。两条材料即使只共享一个非缺失维度，也可能得到接近 `±1` 的余弦值，显示层无法区分“高重叠、高相似”与“低重叠、偶然同向”。

### A2. 方差分母使用总产品数

原实现把缺失值填成均值后，用总产品数减一作为样本方差分母。缺失越多，方差越容易被人为压低，继而放大有效观测的 Z-score。

### A3. 宽松数值转换

`Number('') === 0`，空字符串会被误当作真实零值；非有限数值和部分异常文本也缺少独立诊断。

### A4. 空白特征名和重复产品 ID 未拒绝

空白键没有科学含义；重复产品 ID 会让网络边端点产生歧义。

## 3. 相似度修复合同

新模型版本：`zscore-cosine-overlap-f64-3.0.0`。

对每个特征仅使用真实有限观测计算均值与样本标准差：

$$
\bar{x}_j=\frac{1}{n_j}\sum_{i\in O_j}x_{ij},\qquad
s_j=\sqrt{\frac{1}{n_j-1}\sum_{i\in O_j}(x_{ij}-\bar{x}_j)^2}
$$

无足够观测或零方差的特征不进入有效特征集合。缺失值在 Z-score 空间中记为零，同时保留独立 `Uint8Array` 观测掩码。

对材料对 $(a,b)$，先计算单位化 Z-score 向量的原始余弦，再乘共享有效特征覆盖率：

$$
s_{ab}=\operatorname{clip}(\mathbf z_a^\top\mathbf z_b,-1,1)
\frac{|F_a\cap F_b|}{|F_{\mathrm{active}}|}
$$

并要求至少共享两个有效特征。边结果显式携带：

- `rawCosine`；
- `featureCoverage`；
- `sharedFeatures`；
- 调整后的 `value`。

这不是化学等价概率，也不是因果或机理结论。

## 4. 凸包原实现的确定性问题

- 精确重复坐标未去重；
- 全共线输入可能经过多余极角排序并形成不透明的退化路径；
- `ccw === 0` 使用精确浮点比较，尺度相关的舍入噪声可能生成伪顶点；
- 注释称“深拷贝”，实际仅复制数组引用；
- 相同点的输出代表记录缺少明确的确定性规则。

## 5. 凸包修复合同

公开 API `grahamScan(points)` 保持不变，内部改为 Andrew monotone chain：

- 过滤非有限坐标；
- 按 `(x,y,原索引)` 确定性排序；
- 精确重复坐标保留输入中第一个记录；
- 使用尺度相关浮点容差判断近共线；
- 删除共线内部点，只保留边界端点；
- 输出从字典序最小点开始、逆时针排列；
- 不修改调用方数组或点对象。

复杂度保持 `O(n log n)`，但比较器不再反复计算极角和基点距离。

## 6. 自动化测试

新增：

- `tests/science/similarityMissingness.test.ts`：6 项缺失、覆盖率、严格解析、无效特征与 ID 合同；
- `tests/unit/convexHull.test.ts`：6 项重复点、全共线、近共线、非有限点、不可变性和排列确定性合同。

现有相似度有界边内存测试同步锁定新模型版本和掩码/覆盖率诊断。

## 7. 保留边界

- 相似度仍是全产品对精确计算，时间复杂度为 `O(n²d)`；本轮没有用近似最近邻替代；
- 覆盖率线性惩罚是明确的数据完整性合同，不应解释为统计置信概率；
- 凸包只表达二维投影边界，不表示材料真实可行域、相图边界或制造窗口；
- 最终接受状态取决于 TypeScript、完整测试、覆盖率、构建、HTTP、Chromium 与两级依赖审计。
