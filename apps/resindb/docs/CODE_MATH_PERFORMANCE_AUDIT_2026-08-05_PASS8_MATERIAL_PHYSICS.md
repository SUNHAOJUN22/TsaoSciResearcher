## 2. 已确认的统计数理问题

### A1. Pearson 显著性错误使用标准正态近似

原 `calculatePValue()` 先计算

$$
t=r\sqrt{\frac{n-2}{1-r^2}}
$$

但随后把该统计量代入标准正态 CDF。Pearson 相关在零相关假设下应使用自由度 $\nu=n-2$ 的 Student-$t$ 分布。小样本误差明显，例如 $r=0.5,n=10$：

- 正确双侧 $p=0.14111328125$；
- 正态近似会给出更小的显著性概率，扩大假阳性风险。

### A2. 95% 斜率区间固定使用 `t = 2.0`

原 `calculateSlopeConfidenceInterval()` 与 `calculateCI()` 均固定使用 `2.0`。当 $n=4$、自由度为 2 时，正确临界值为：

$$
t_{0.975,2}=4.3026527297
$$

原区间因此严重偏窄。

### A3. Spearman 并列值未使用平均秩

原实现直接按排序位置赋秩，并使用无并列假设下的 $1-6\sum d_i^2/[n(n^2-1)]$。对材料数据库常见的离散等级、四舍五入值和检测下限数据，该实现会产生错误相关系数。

### A4. 原始和式回归存在大偏置坐标消减误差

原回归依赖 $n\sum xy-\sum x\sum y$。当坐标具有很大的共同偏置、但变化量较小时，两个大数相减会丢失有效位数。新实现使用中心化在线协方差：

$$
S_{xx}=\sum_i(x_i-\bar x)^2,\qquad
S_{xy}=\sum_i(x_i-\bar x)(y_i-\bar y)
$$

并由 $\hat\beta_1=S_{xy}/S_{xx}$ 求解。

### A5. 线性坐标界限错误删除负值

原 `calculateBounds()` 无论是否为对数轴，都只保留 `v > 0`。这会使负温度、负偏差、负响应等合法线性数据消失。原实现还使用 `Math.min(...array)` / `Math.max(...array)`，百万级数组会触发参数栈 `RangeError`。

### A6. 雷达百分位重复排序

雷达图展示 6 个牌号、6 个维度时，原路径对每一次显示查询都复制并排序完整参考数组，即 36 次排序。新路径按参考数组对象缓存每个维度的排序结果，再使用二分查找计算并列平均秩；现有显示调用无需改写即可复用缓存。

### A7. 描述统计合同不一致

- 偶数样本中位数原来取上中位数；
- `getStats()` 与 `calculateQuartiles()` 使用不同分位数算法；
- Spearman、IQR 和描述统计的并列/插值行为不一致；
- 样本偏度和峰度修正公式配合了总体标准差，产生系统偏差。

### A8. 流变文本宽松解析

原 `Number()` 会把空字符串转为零，并接受非正剪切速率或黏度。新解析只接受完整十进制/科学计数法且要求两个值均为正有限数。

## 3. 已确认的聚合物物理问题

### A9. 单体身份被错误升级为聚合物微结构

原描述符从丙烯单体直接输出“等规 PP”和固定等规指数，从乙烯单体直接输出 HDPE。单体身份不能决定：

- tacticity；
- 支化结构；
- 共聚组成；
- 分子量分布；
- 结晶度和加工历史。

原自定义 fallback 还按字符计数生成分子量、Tg、密度和化学式，属于无明确适用域的伪 QSPR。初版候选仍把未给定乙烯/丙烯/二烯配比的 EPDM 片段压缩成单一“分子量”和伪重复单元，并把 PS 标为中等极性；终审版本进一步拒绝组成不确定的 EPDM 输入，并将 PS 保守归为非极性材料。

### A10. LAMMPS 拉伸段初始长度没有真正冻结

原模板：

```lammps
variable L0 equal lx
variable strainX equal (lx-v_L0)/v_L0
```

`equal` 变量会动态求值，因此 `v_L0` 会跟随 `lx` 变化，工程应变可能持续接近零。新模板在平衡后通过立即求值冻结初始长度：

```lammps
run 0
variable L0 equal $(lx)
```

### A11. LAMMPS 应力分量与单位错误

原模板使用 `-press`，这是静水压力，不是拉伸方向的 $\sigma_{xx}$；`units real` 下压力单位为 atm，但输出没有转换。新模板使用：

$$
\sigma_x[\mathrm{MPa}]=-p_{xx}[\mathrm{atm}]\times0.101325
$$

并把 `fix deform` 改为 `remap x`。终审版本还把冷却起点、终点、步数、时间步长和 MSD 原子组纳入显式输入验证；默认 MSD 组为 LAMMPS 内置 `all`，自定义组必须是已存在的单 token 组名。模板明确说明：未提供反应力场时不能宣称预测断裂，也不能把快速 MD 冷却直接解释为实验冷却过程或仅凭 MSD 判定 Tg。

### A12. QSPR 输入可产生 NaN 或无物理意义输出

原函数允许负 MFR、零或负拉伸强度及非有限密度进入分数次幂。结晶度采用简单线性密度插值，并把经验关系错误标注为 Halpin–Tsai。新实现：

- 在计算前验证有限值和支持范围；
- 使用 PP 两相密度质量分数关系；
- 将输出标记为 `pp-screening-heuristic-2.0.0`；
- 限制硬度、伸长和冲击代理范围，并移除由 PP 输入推算 EPDM 溶胀的越域输出；
- 返回明确适用域与警告。

两相密度关系：

$$
X_c=\frac{\rho_c(\rho-\rho_a)}{\rho(\rho_c-\rho_a)}
$$

### A13. ASTM/ISO 筛查存在严格解析、单位和严重度问题

原 `Number('')=0` 会把空白字段当作真实零；不同单位没有转换；缺失单位会被默认为内部单位；当同一记录另有有效属性时，格式错误字段可能被静默忽略；后出现的 WARNING 可能把先前 CRITICAL 状态降级；`includes('pp')` 风格类别识别可能把 PPS 等类别误判为 PP。

新实现：

- 完整十进制/科学计数法解析；
- 支持密度 `g/cm³ ↔ kg/m³`；
- 支持应力/模量 `Pa/kPa/MPa/GPa`；
- 支持 MFR `g/10 min` 与 `kg/10 min`；
- 缺失或不支持的单位显式警告并跳过；
- 即使同一记录另有可筛查属性，也保留格式错误/非有限字段的数据质量告警；
- 严重度只允许 `PASSED → WARNING → CRITICAL` 单向升级；
- 使用精确类别别名识别 PP、HDPE，不把 PPS 识别为 PP；
- 明确结果是工程合理性筛查，不是标准符合性证书。

## 4. 实施后的统计合同

### 4.1 Student-t 双侧相关显著性

$$
p=I_{\nu/(\nu+t^2)}\left(\frac{\nu}{2},\frac12\right),
\qquad \nu=n-2
$$

其中 $I_x(a,b)$ 为正则化不完全 Beta 函数。实现使用 Lanczos $\log\Gamma$ 和稳定连分式，并将 95% 临界值按自由度缓存。

### 4.2 Spearman 平均秩

$$
\rho_s=\operatorname{corr}(R_x,R_y)
$$

并列值取其位置秩的算术平均值；常量秩向量按现有显示合同返回 0。

### 4.3 样本偏度与超额峰度

使用样本标准差与有限样本修正，测试结果与 SciPy `bias=False`、`fisher=True` 在固定夹具上相符。

### 4.4 分子量矩缩放

先以最大分子量缩放 $M_i$，并以最大强度缩放相对权重，再计算 $M_n,M_w,M_z$，避免 $M_i^3$ 或极大强度求和导致不必要溢出。输出明确标记为 `relative-number-intensity` 基础；代理 GPC 曲线仍不是实测 GPC 数据。

## 5. 性能核验

本地环境：Node.js 22.16.0；预热后 7 次取中位数。

### 5.1 雷达中位秩路径

固定夹具：100,000 个参考值，36 次显示查询。

| 实现 | 中位时间 |
|---|---:|
| 原：每次查询复制并排序 | 1,101.91 ms |
| 新：一次排序 + 二分中位秩 | 32.52 ms |
| 当前夹具加速 | 约 33.9× |

### 5.2 坐标界限

固定夹具：1,000,000 个有限线性值。

- 新单遍扫描：约 `8.38 ms`；
- 原 `Math.min(...values)` 在该规模触发 `RangeError: Maximum call stack size exceeded`。

时间结果只描述当前设备和固定夹具，不构成跨设备固定倍数承诺。

## 7. 保留边界

- 相关与回归仍是观测关联，不是因果推断；
- 95% 区间依赖独立、同方差、线性残差等经典假设；
- 雷达 20–100 中位秩只用于显示，不是绝对性能百分比；
- PP-like QSPR 仍是经验筛选，不是已验证的通用模型；
- 单体描述符库不推断 tacticity、支化、共聚比例或分子量分布；组成不确定的 EPDM 输入直接拒绝；
- LAMMPS 模板不生成拓扑和力场系数，也不保证裂纹或断键；
- ASTM/ISO 审计是范围筛查，不是认证、放行或标准符合性结论；
- 最终接受状态仍以完整仓库 CI、Chromium、构建、覆盖率和依赖审计为准。
