# Security and High-Stakes Use

OpenDeepMind is a reasoning workflow, not a substitute for professional authorization, laboratory validation, legal interpretation, medical diagnosis, financial fiduciary review, or safety certification.

## Report an issue

Report privately to the repository owner when an issue could cause:

- unsafe removal of safeguards;
- misleading medical, legal, financial, or safety guidance;
- source fabrication;
- privacy leakage;
- harmful automation of decisions about people;
- execution of untrusted code;
- supply-chain compromise.

Do not include secrets, personal records, or exploit payloads in a public issue.

## Safe-use expectations

- Verify current high-stakes facts with authoritative sources.
- Keep rights, legal duties, and safety controls as hard constraints until verified otherwise.
- Treat generated analyses as reviewable artifacts.
- Preserve human accountability and appeal mechanisms.
- Run bundled scripts only from a trusted checkout and review changes before execution.
