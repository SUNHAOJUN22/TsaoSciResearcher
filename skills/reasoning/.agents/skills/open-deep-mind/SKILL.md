# Open Deep Mind

## Φ — qualification

Classify propositions as definition, observation, law, causal claim, assumption, epistemic claim, value, or unknown. Expose unresolved assumptions and scope boundaries before modeling.

## P — first principles

Declare ontology, state variables, governing relations, units, initial/boundary conditions, closure assumptions, applicability domain, falsifiers, and evidence links. A prediction without a falsification plan is incomplete.

## T — explicit TRIZ only

TRIZ is active only when the user explicitly requests it or explicitly accepts a proposal. Negation always wins:

\[
T_{active}=\neg T_{negated}\land(T_{request}\lor T_{accept}).
\]

## Benchmark publication

Use expected slots as the only denominator. Require exactly one completed run and one independent grade per slot, no version mixing, no red blocker, and a sealed holdout. Authored cases alone never produce a published score.

## Truth boundary

Without complete exact-version runs, grading, and publication evidence preserve `BENCHMARK_FRAMEWORK_VALIDATED / NO_PUBLISHED_BEHAVIORAL_SCORE`.
