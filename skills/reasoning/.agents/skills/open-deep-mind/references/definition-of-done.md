# Definition of done

- Every proposition has one explicit type, status, scope, and evidence relation.
- First-principles models declare variables, units, boundaries, closures, domain, and falsifiers.
- TRIZ is enabled only by explicit request or acceptance and disabled by negation.
- Cross-scale bridges identify preserved quantities and error/uncertainty propagation.
- Benchmark completeness uses expected slots, not authored-case count.
- Duplicate, missing, orphaned, mixed-version, holdout-leaking, or red-blocked results cannot publish.
- Static routing cases and benchmark definitions are never reported as actual model runs.
