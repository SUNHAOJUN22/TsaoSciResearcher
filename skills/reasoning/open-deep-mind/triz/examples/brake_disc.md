# Worked Example — Brake Disc Thermal Fade

> Demonstration only. Numerical thresholds/material selections require current brake-system data and engineering verification.

## 0. Scope

- System: disc brake.
- Main function: convert vehicle kinetic energy into controlled deceleration.
- Initial disadvantage: repeated/high-energy braking raises disc/pad temperature and can reduce friction stability/reliability.
- Resources: disc geometry, rotating airflow, thermal mass, vehicle structure, control timing.

## 1. Function / problem identification

Useful interaction:

```text
pad → frictionally loads → disc
```

Harmful associated effect:

```text
friction work → heat → temperature rise → friction/material degradation risk
```

Key problem chosen for the example: increase useful braking action/thermal capacity while avoiding unacceptable temperature/reliability penalty.

## 3. IFR

```text
The braking system dissipates the heat generated by braking
using resources already created by wheel/disc motion and geometry,
without a dedicated high-burden cooling subsystem,
while preserving required friction, strength, serviceability and packaging.
```

## 4. Concept families

### A. Internal ventilation / flow-structured disc

- TRIZ routes: segmentation, another dimension, flow enhancement, local quality.
- Mechanism: use internal vanes/channels to increase effective heat-transfer area and move ambient air using rotation/pressure differences.
- Resource: rotating airflow + internal volume.
- Secondary contradictions: mass/stiffness, manufacturing complexity, balance, debris/noise.
- Validation: conjugate heat-transfer model, stress/fatigue analysis, bench dynamometer.

### B. Surface/local-quality thermal architecture

- TRIZ routes: local quality, porous/structured material, parameter changes.
- Mechanism: keep friction track optimized for tribology while non-friction regions are optimized for heat transfer/flow.
- Resource: unused/non-contact surfaces.
- Secondary contradictions: crack initiation, corrosion, manufacturability.

### C. Time/condition-based braking control

- TRIZ routes: periodic action, feedback, separation in time/condition.
- Mechanism: use sensing/control to redistribute braking effort, pulse/alternate actions, or use regenerative braking where the supersystem permits.
- Resource: control system, drivetrain/electrical supersystem.
- Secondary contradictions: driver feel, control stability, safety certification, battery/motor limits.

### D. Phase-transition thermal buffer

- TRIZ routes: phase transition, parameter changes.
- Mechanism: store peak transient heat in a material/state transition and release it between events.
- Resource: thermal gradient / dwell time.
- Secondary contradictions: mass, containment, durability, cyclic stability.

## 5. Rejected compromise

“Simply reduce braking capability to keep temperature low” does not resolve the stated contradiction if required deceleration remains a hard constraint.

## 6. Substantiation

For each concept calculate/measure:

- transient heat generation and removal;
- disc/pad temperature field;
- thermal stress and fatigue;
- friction coefficient stability;
- mass/inertia;
- packaging and balance;
- failure modes and safety margins.

## 7. Lesson

TRIZ supplies structurally different search directions; the final brake design is selected by physical modeling, testing, manufacturability, safety, and the OpenDeepMind quality gate—not by the principle name.
