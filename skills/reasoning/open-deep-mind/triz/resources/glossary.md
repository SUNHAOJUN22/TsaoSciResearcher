# TRIZ Operational Glossary / TRIZ 操作术语表

Definitions are aligned where possible with the public MATRIZ glossary; wording is compressed for agent use.

| Term | 中文 | Operational definition |
|---|---|---|
| TRIZ | 发明问题解决理论 | applied discipline for directions and methods of engineering-system improvement |
| Engineering system | 工程系统/技术系统 | intentionally developed system that performs a function |
| Supersystem | 超系统 | system/environment containing the analyzed engineering system as a component |
| Main function | 主功能 | function for which the engineering system was designed |
| Target component | 目标组件 | object of the system's main function |
| Function | 功能 | action by a material object that changes or maintains a parameter of another material object |
| Function carrier | 功能载体 | material object performing a function |
| Useful function | 有用功能 | required change/maintenance of an object's parameter |
| Harmful function | 有害功能 | unacceptable change/maintenance of an object's parameter |
| Measurement function | 测量功能 | function revealing information about system components/state |
| Function model | 功能模型 | system/supersystem model describing functions, usefulness/performance, and optionally costs |
| Function disadvantage | 功能缺点 | harmful, insufficient, or excessive function |
| Flow | 流 | movement of substance, energy/field, or information in an engineering system |
| Flow disadvantage | 流缺点 | bottleneck, stagnation, harmful/wasted/poorly used/maldistributed flow, etc. |
| Initial disadvantage | 初始缺点 | inversion of the project goal; CECA starting point |
| CECA | 因果链分析 | cause–effect chain analysis linking initial disadvantage to deeper disadvantages/key disadvantages |
| Key disadvantage | 关键缺点 | selected disadvantage whose elimination materially supports project goal |
| Key problem | 关键问题 | selected problem to solve, often derived from CECA, trimming, or feature transfer |
| Engineering contradiction (EC/TC) | 工程/技术矛盾 | improving one parameter through an approach worsens another parameter |
| Physical contradiction (PC) | 物理矛盾 | two justified opposite demands on one parameter of one object/element |
| Typical parameters | 典型参数 | 39 generalized parameters forming contradiction-matrix axes |
| Contradiction matrix | 矛盾矩阵 | 39×39 access mechanism from EC parameter pair to inventive-principle suggestions |
| Inventive principle | 发明原理 | abstract solution model recommending a system transformation |
| Separation | 矛盾分离 | resolving PC by time, space, condition, or system level |
| Su-Field | 物场模型 | abstract problem/solution model in terms of two substances and a field interaction |
| Substance | 物质/物体 | material object with rest mass in Su-Field terminology |
| Field | 场 | interaction carrier; MATRIZ uses MATChEM categories such as mechanical, acoustic, thermal, chemical, electrical, magnetic/EM |
| Incomplete Su-Field | 不完整物场 | missing a required substance and/or field |
| Insufficient Su-Field | 不足物场 | complete model whose useful interaction is inadequate |
| Harmful Su-Field | 有害物场 | model with harmful/excessive interaction |
| Standard Inventive Solutions (SIS) | 标准解 | 76 typical solution models for Su-Field problem models |
| Fe-Field | 铁磁物场 | Su-Field using segmented magnetic material and electromagnetic control |
| ARIZ | 发明问题解决算法 | deep algorithm transforming complex key problem into sharper models and guiding use of TRIZ tools |
| Mini-problem | 最小问题 | key problem constrained against major system changes |
| Product (ARIZ) | 产品/作用对象 | element that must be processed, changed, protected, measured, etc. |
| Tool (ARIZ) | 工具 | object directly interacting/conflicting with product |
| Conflicting pair | 冲突对 | product–tool pair whose interaction causes the conflict |
| X-factor | X 因子 | required unknown change that must solve the ARIZ problem model |
| Operating zone (OZ) | 操作区 | physical region where contradiction requirements/conflict occur |
| Operating time (OT) | 操作时间 | time intervals in which contradiction requirements must hold |
| Substance–field resources (SFR) | 物场资源 | available substances, fields, voids, space/time, byproducts and system/supersystem resources |
| Ideal Final Result (IFR) | 理想最终结果 | best solution model for a specific inventive problem: eliminate problem with minimal changes and no relevant deterioration |
| Ideal system | 理想系统 | limiting concept with maximal/infinite value: function remains while components/payment factors tend toward zero |
| Ideality | 理想度 | ratio/relationship between benefits and payment factors such as cost, space, maintenance, harm, risk |
| Trimming | 裁剪 | eliminate component/operation and redistribute/eliminate its necessary useful functions |
| Partial trimming | 部分裁剪 | redistribute some useful functions while retaining a reduced/unloaded component |
| Trimming problem | 裁剪问题 | key problem generated by a proposed trimming model |
| Base system | 基础系统 | system selected for feature-transfer improvement |
| Competing system | 竞争系统 | system performing same/similar main function |
| Alternative system | 替代系统 | competing system with complementary advantage/disadvantage relative to base |
| Feature transfer | 特征迁移 | transfer useful feature/mechanism from alternative to base system, resolving incompatibilities |
| Feature-transfer problem | 特征迁移问题 | key problem preventing desired transfer |
| FOS | 功能导向搜索 | search for existing technologies worldwide by generalized function, especially leading areas |
| Generalized function | 广义功能 | function stated in universal terms with industry-specific details abstracted away |
| Database of scientific effects | 科学效应数据库 | function/resource-oriented collection of physical, chemical, biological etc. phenomena |
| TESE | 工程系统进化趋势 | empirically/statistically derived engineering-system development directions |
| S-curve | S 曲线 | evolution of a system MPV against time through emergence, growth, maturity, decline/replacement |
| MPV | 主要价值参数 | attribute important to purchasing/system value and technology evolution |
| Increasing value | 价值提升趋势 | system value tends to increase through greater useful effect and/or lower payment factors |
| Increasing dynamization | 动态化趋势 | system/components gain flexibility, adjustability, degrees of freedom |
| Increasing controllability | 可控性提升趋势 | system gains more ways to influence relevant states/parameters |
| Flow enhancement | 流强化趋势 | useful flows become more conductive/useful; harmful flows are reduced or controlled |
| Transition to supersystem | 向超系统转移 | integration/hybridization with supersystem/other systems to obtain resources/functions |
| Decreasing human involvement | 人参与减少趋势 | engineering system progressively takes over functions previously performed by humans |
| Concept substantiation | 概念论证 | feasibility/business/technical evaluation and evidence development after solution generation |

```text
inferred/direct-principle selected from the 40 principles outside matrix lookup
separation-*              derived from physical-contradiction separation
standard-solution-*       derived from one of the 76 SIS
ARIZ-derived              obtained through deep ARIZ route
FOS-derived               adapted from an existing technology found by function search
effect-derived            based on a scientific effect/phenomenon
trend-derived             generated as a TESE/S-curve roadmap hypothesis
TRIZ-derived              concept generated, not yet physically validated
validated                 forbidden unless the downstream evidence/quality gate supports it
```
