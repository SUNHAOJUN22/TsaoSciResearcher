# 39 Engineering Parameters / 39 个典型工程参数

## Mapping rules

1. Map the real engineering variable to the closest generalized parameter only after defining the physical quantity and failure mechanism.
2. A real variable may justify more than one mapping. When uncertain, retain 2–3 candidates and compare matrix results.
3. Do not force business, UX, social, or organizational metrics into these 39 parameters merely to make TRIZ appear applicable.
4. Respect directionality: `(improving, worsening)` is not interchangeable with `(worsening, improving)`.
5. A matrix recommendation is a search direction, not proof that the mapped parameter or proposed embodiment is correct.
