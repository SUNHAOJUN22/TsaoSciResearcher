# Bilingual Glossary / 双语术语表

| English | 中文 | Working meaning in OpenDeepMind |
|---|---|---|
| First Philosophy | 第一哲学 | Inquiry that qualifies the most basic commitments of a question: meaning, being, knowledge, logic, causality, boundary, value, and action |
| First Principles | 第一性原理 | Task-relative starting points that cannot be further decomposed without leaving the chosen domain, scale, or purpose |
| Foundation | 基础 / 基底 | A premise or commitment provisionally accepted as a starting point |
| Working foundation | 工作性基础 | A defeasible foundation justified enough for current action |
| Ground truth | 基底事实 / 基础事实 | A carefully qualified definition, observation, law, constraint, or value; not a synonym for “my strong belief” |
| Ontology | 本体论 | Account of what entities, processes, relations, properties, or absences are treated as real |
| Epistemology | 认识论 | Account of what is known, how it is known, and with what warrant |
| Semantics | 语义 | Meaning, reference, and use of terms |
| Axiology | 价值论 | Inquiry into value, goals, and what is worth pursuing |
| Praxis | 实践 | Action guided by reflection under real conditions |
| Category mistake | 范畴错误 | Treating something as belonging to a type it does not belong to |
| Reification | 实体化 / 物化 | Treating an abstraction, proxy, or model variable as a concrete independent thing |
| Causal identification | 因果识别 | Conditions under which a causal quantity can be recovered from data and assumptions |
| Mechanism | 机制 | Organized entities and activities that generate a phenomenon |
| Constitutive explanation | 构成性解释 | Explanation of what makes a phenomenon the kind of thing it is |
| Efficient/generative cause | 动力因 / 生成性原因 | Process that brings about a change |
| Enabling condition | 使能条件 | Background condition without which the process cannot occur |
| Constraint | 约束 | Condition a feasible solution must satisfy |
| Assumption | 假设 | Adopted premise not established as fact |
| Empirical closure | 经验闭合关系 | Fitted or phenomenological relation used to close an otherwise underdetermined model |
| Observation model | 观测模型 | Mapping from latent/system states to measured data |
| Model discrepancy | 模型结构误差 | Difference between reality and the model class, beyond parameter/noise error |
| Scale bridge | 尺度桥接 | Mapping and closure that connect variables and behavior across scales |
| Falsifier | 证伪条件 | Result that would materially lower confidence or reject a claim/model |
| Counter-model | 竞争模型 / 反模型 | Serious rival explanation, frame, or design |
| Null model | 零模型 | Baseline representing no proposed mechanism/effect beyond specified background |
| Sensitivity | 敏感性 | Change in output caused by variation in assumptions or parameters |
| Robustness | 鲁棒性 | Ability to maintain acceptable outcomes across plausible uncertainty |
| Value of information | 信息价值 | Expected decision improvement from acquiring information |
| Reversibility | 可逆性 | Degree to which a decision can be undone without unacceptable loss |
| Traceability | 可追溯性 | Ability to connect a conclusion to premises, evidence, models, and decisions |
| Foundation Charter | 基础章程 | First Philosophy deliverable that records active foundational commitments |
| Proposition ledger | 命题账本 | Typed register of definitions, observations, laws, constraints, assumptions, closures, values, and unknowns |
| Red blocker | 红色阻断项 | Defect that prevents a result from being called validated or complete |
| Progressive disclosure | 渐进式披露 | Loading metadata first, core instructions on activation, and detailed resources only when needed |
