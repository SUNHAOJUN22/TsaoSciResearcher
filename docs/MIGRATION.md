# 单仓库迁移记录

唯一目标仓库为 `SUNHAOJUN22/TsaoSciResearcher`，产品名为 TsaoScience，版本为 astra-pro-1。

来源版本与目标位置固定在 `migration/source-lock.json`。`migration/source-map.json` 对每个原文件给出唯一目标位置及原始 SHA-256；修改后的对应摘要独立记录在 `migration/patches.json`。文件移动不是删除，原模块的测试、示例、文档、许可和数据分类均保留。新增加的集成代码有独立文件清单。

根目录不再把 Researcher 当成独立产品，其原源码也迁入组件层，与其他领域实现受到同一集成入口约束。原工作流位于组件子目录，不再作为七套根流水线运行。根 CI 的每个作业必须报告自己的验证范围。

旧仓库的退役顺序：固定原提交与来源清单 → 迁移文件并核对 → 执行集成及相关原回归 → 发布唯一目标位置 → 再将旧仓库平台归档。不得在迁移核对前删除原仓库，也不得以写入一个说明文件代替 GitHub 平台归档。平台改名、归档和删除属于仓库管理权限，需分别记录是否实际执行。

受控数据不因为迁移而变成公开授权数据。完整分发继续由原策略阻断；迁移源码、软件验收和公开发行是不同操作。
