# 第一性原理计算与仿真策略顾问

TsaoSciResearcher 0.7.0 新增确定性的策略建议层：从科研问题的可观测量和底层物理出发，形成“最低充分方法—升级方法—验证/证伪—不确定性”的计算或仿真阶梯。该模块**不运行** DFT、MD、FEM、CFD、流程模拟或其他求解器。

## 为什么需要该模块

直接从问题跳到软件名称，不能构成可靠的科研方案。方法必须由以下因素决定：控制可观测量的状态变量、守恒量与对称性、热力学或非平衡状态、关键长度/时间/能量尺度，以及可用于验证和证伪的证据。

这里的“第一性原理”采用广义科学含义，而不是“所有问题都做 DFT”：电子态问题可能需要量子力学；自由能问题需要统计系综和采样；高分子形貌可能需要统计场或介观模型；压降问题通常应从守恒方程和本构关系开始。

## 八阶段推理链

1. **决策与可观测量**：明确量、单位、容差、基准和决策阈值。
2. **自由度**：识别能改变可观测量的电子、分子、场、群体、结构或内变量。
3. **精确约束**：守恒律、对称性、化学计量、正性、几何和可容许性。
4. **物理框架**：量子、统计物理、热力学、连续介质、动力学或混合框架。
5. **状态与库**：选择热力学势/统计系综，判断平衡、亚稳、老化或驱动非平衡。
6. **尺度分析**：比较长度、时间、能量、相关、松弛和外部驱动尺度，必要时使用无量纲数。
7. **方法阶梯**：从最低充分模型开始，规定由证据触发的升级条件。
8. **验证和真实性边界**：定义收敛、证伪、UQ、竞争机理、外部执行、回执、结果审查和人工接受。

## 支持的策略族

- 电子结构、缺陷、界面与量子态；
- 反应路径、催化、过渡态和微观动力学；
- 分子热力学、构象、溶剂化和自由能；
- 高分子/软物质形貌、结晶和相分离；
- 连续介质流动、传热传质和非牛顿输运；
- 固体力学、黏弹性、断裂和失效；
- 电荷输运、陷阱、介电响应和击穿；
- 工艺动力学、反应器、群体平衡和分布；
- 具有明确桥接变量的混合与多尺度问题。

## 命令

```bash
python -m tsao_researcher strategy \
  "陷阱态和形貌如何控制空间电荷与击穿？" \
  --observable "空间电荷" \
  --observable "击穿强度" \
  --condition "外加电场" \
  --evidence "PEA 电荷分布" \
  --output strategy.json

python scripts/validate_computation_strategy.py strategy.json
```

输出受 `schemas/v2/computation-strategy.schema.json` 约束，并必须明确 `solver_executed: false`。

## 方法选择原则

先选择能够因果决定目标可观测量、且可以被独立证伪的最低成本模型。只有当验证失败明确指出缺少某个自由度、耦合或尺度时才升级。单一数据集的吻合不能证明机理成立。

## 外部执行边界

经过审核的策略可以转换为带校验和的 handoff。真实运行、日志、输出、收敛和回执仍由外部系统产生。TsaoSciResearcher 负责审查返回证据，并严格区分 `executed`、`checked`、`validated` 和 `accepted`。

## 科学问题到方法阶梯

| 物理区间 | 最低充分起点 | 证明缺少物理后再升级 |
|---|---|---|
| 电子基态与缺陷 | 电荷/自旋/对称性记账；收敛 DFT | 杂化泛函、嵌入或波函数基准 |
| 激发态与光谱 | 态性质和选择定则；TDDFT | GW/BSE、多参考或非绝热动力学 |
| 反应与催化 | 热力学网络一致性；DFT/NEB/过渡态 | 增强采样、微观动力学、kMC 与反应—输运耦合 |
| 分子自由能 | 定义统计系综；MD/MC 与自由能估计 | QM/MM、从头算 MD 或经验证的粗粒化 |
| 高分子形貌 | 标度/SCFT 与序参量选择 | CGMD/DPD/相场，再进行经验证的跨尺度闭合 |
| 连续介质输运 | 守恒平衡、本构闭合和无量纲分析 | 网格收敛 CFD 与耦合多物理场 |
| 力学与断裂 | 能量、对称性和本构可识别性 | FEM、相场/黏聚断裂和微结构模型 |
| 电荷输运与击穿 | 陷阱/注入态分析和电荷守恒 | kMC/漂移—扩散—Poisson、电热与随机失效 |
| 流程与群体 | 质量/能量平衡和可识别性 | PBE/反应器网络、CFD/流程与贝叶斯校准 |
| 混合问题 | 明确可观测量、库、尺度和证伪目标 | 顺序、含不确定度的多尺度耦合 |

## 保持真实性的方法升级规则

1. 推荐求解器只是计划，不是执行。
2. Execution Receipt 只能证明进程运行过，不能证明已经收敛。
3. 数值收敛不能自动证明模型有效。
4. 针对一个可观测量的模型有效性不能自动证明因果机理。
5. 科学接受需要与论断风险相匹配的独立证据和合格审查。
