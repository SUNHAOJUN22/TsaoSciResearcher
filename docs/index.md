# TsaoSciResearcher

TsaoSciResearcher is an evidence-first control layer for scientific research. It separates planning, execution evidence, validation and final scientific acceptance.

## v0.6.0 highlights

- deterministic reproducibility capsules;
- checksum-verified external execution receipts;
- validation evidence schema 1.6 and external commit attestation;
- line/branch coverage, mutation, performance and order-independence gates;
- deterministic CycloneDX 1.6 SBOM and dependency vulnerability audit;
- wheel, sdist and source-ZIP validation;
- permanent idempotent CI, manual audit, nightly health and tag release workflows.

A PASS result validates declared software controls. It does not certify an external experiment or scientific conclusion.
